# Документы сайта

Сайт — особый проект студии: статические страницы и установщики машины, без `package.json`
и без игры; поэтому набор документов короче обычного
([`docs/04-process.md`](https://github.com/Nefeste/gornitsa/blob/main/docs/04-process.md#документация-живёт-в-репозитории) устава).
Состояние — [`STATUS.md`](../STATUS.md). Порядок чтения:

1. [`README.md`](../README.md) — структура, как собрать и поменять текст, новости, поиск, реквизиты продавца,
   обновление сайта, проверка PR.
2. [`game-pages.md`](game-pages.md) — страницы игр из `store/site/` игр, ночной PR, публикация в RuStore.
3. [`machine.md`](machine.md) — машина: запуск с нуля, вход, мониторинг, копии баз, «Сени»,
   серверы игр, закрытая веб-версия «Узоров».
4. [`backup.md`](backup.md) и [`restore.md`](restore.md) — копии баз и восстановление с нуля.
5. [`devlog.md`](devlog.md) — «Дневник разработки».
6. [`journal/`](journal/) — журнал по месяцам, `ГГГГ-ММ.md`.

Правила студии — только в уставе
[`Nefeste/gornitsa`](https://github.com/Nefeste/gornitsa); здесь не пересказываются.
