The studio in brief

Name
Gornitsa, in Russian «Горница»
What we make
mobile games for RuStore
Games
Votchina — on RuStore and in the browser; four more in development

Gornitsa makes calm, honest and clear games rooted in Russian culture: a tile-laying board game and backgammon, a role-playing game based on Russian fairy tales and bylinas, a cross-stitch colouring game and a doctor simulator. Each game comes out on RuStore first, for affordable Android phones, and the studio supports it itself. What we promise players — nine promises.

How to write the name: Gornitsa, without quotation marks (Gornitsa Studio). Game names: Votchina, Long Nardy, Anamnesis, Skazy, Uzory; the names of the new games are working titles.
