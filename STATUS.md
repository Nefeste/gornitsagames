# Состояние

**Сайт:** https://gornitsa.games — статический, на русском и английском: главная, страницы
пяти игр (собираются из `store/site/` игр, ADR студии 0015), новости с лентами Atom, «Для прессы»,
«О студии», брендбук, поддержка, политика конфиденциальности. «Вотчина» — в RuStore, остальные
игры — в разработке. Та же машина держит серверы «Вотчины», нард и «Сказов», закрытую
веб-версию «Узоров», мониторинг и зашифрованные копии баз для компьютера владельца; «Сени» — на своей машине, здесь только установщик.

**Как меняется:** через PR; все PR сайта сливает владелец, слияние — публикация
([`.github/CODEOWNERS`](.github/CODEOWNERS), ADR студии 0018). Ночной PR
«Сайт: обновления игр» — workflow `games.yml`.

**Ждёт владельца:**

- защита `main` с «Require review from Code Owners» и обязательной проверкой «Проверка сайта»;
- на работающей машине — порядок из README, «Вход на сервер» (`setup-server.sh`,
  `sudo gornitsa-ssh ok`);
- решение №17 — по неделе сводок (README, «Мониторинг машины»);
- копии баз: компьютер владельца в России (03.10.2026) — ключи `sudo gornitsa-backup-keys` здесь
  и на машине «Сеней», забор по [`docs/backup.md`](docs/backup.md);
- поиск (решение №29): сайт в Яндекс Вебмастере и Google Search Console, файлы подтверждения —
  в `/etc/gornitsa-site/verification/`, `sitemap.xml` — в обоих (README, «Поиск…»); через 4 недели
  после подключения Вебмастера — сверка заголовков со «Статистикой запросов»;
- описания страниц игр 120–160 знаков — поле `description` в `store/site/` каждой игры
  (напоминания `tools/check.py`);
- страница разработчика в RuStore — `rustore_developer` в `tools/site.json`, когда «Вотчина»
  переедет на аккаунт ИП (решение №3);

Подробности — [`README.md`](README.md), журнал — [`docs/journal/`](docs/journal/); правила студии — устав
[`Nefeste/gornitsa`](https://github.com/Nefeste/gornitsa).
