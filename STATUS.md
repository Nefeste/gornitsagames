# Состояние

**Сайт:** https://gornitsa.games — статический, на русском и английском: главная, страницы игр (из `store/site/` игр,
ADR студии 0015), новости с лентами Atom, «Для прессы», «О студии», брендбук, поддержка, политика конфиденциальности.
В RuStore — «Вотчина», «Длинные нарды», «Узоры» и «Анамнез» (`status: live`); «Сказы» — `dev`. Та же машина держит
серверы «Вотчины», нард и «Сказов», закрытые веб-версии «Узоров» и «Буквицы», мониторинг и зашифрованные копии баз для
компьютера владельца; «Сени» — на своей машине, здесь только установщик.

**Как меняется:** через PR; все PR сайта сливает владелец, слияние — публикация ([`.github/CODEOWNERS`](.github/CODEOWNERS),
ADR студии 0018). Ночной PR «Сайт: обновления игр» — workflow `games.yml`.

**Ждёт владельца:**

- закрытая веб-версия «Буквицы»: после слияния — `sudo bukvitsa-password` на машине ([`docs/machine.md`](docs/machine.md));
- защита `main` с «Require review from Code Owners» и обязательной проверкой «Проверка сайта»;
- на машине — «Вход на сервер» в [`docs/machine.md`](docs/machine.md) (`setup-server.sh`, `sudo gornitsa-ssh ok`);
- решение №17 — по неделе сводок (`docs/machine.md`, «Мониторинг машины»);
- копии баз: компьютер владельца в России (03.10.2026) — ключи `sudo gornitsa-backup-keys` здесь
  и на машине «Сеней», забор по [`docs/backup.md`](docs/backup.md);
- поиск (решение №29): Яндекс Вебмастер и Google Search Console — README, «Поиск…»; через 4 недели после Вебмастера — сверка заголовков со «Статистикой запросов»;
- описания страниц игр 120–160 знаков — поле `description` в `store/site/` каждой игры
  (напоминания `tools/check.py`);
- страница разработчика в RuStore — `rustore_developer` в `tools/site.json`, когда «Вотчина»
  переедет на аккаунт ИП (решение №3).

**Идеи на потом** (решение владельца 07.11.2026 — отложено): честные цифры студии с источником и датой; «О нас пишут»
на «Для прессы» — после первых публикаций.
